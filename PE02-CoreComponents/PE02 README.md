# Input

The app begins by taking input in the form of an image "icon.png" located in the "assets" directory. Users can interact with the app by entering their favorite course in a TextInput field.

# Process

The app processes the input image by rendering it on the sreen using the image component. User input, in the form of the favorite course entered in the TextInput field, is processed and displayed on the screen.

# Output

The app generates an output interface consisting of various visual components such as image displayed using the image component. User-entered course information is also displayed on the screen. The core, depth of study, and capstone courses are displayed in separate sections, structured with Text and View components, providing essential information to users. The content is made scrollable using the ScrollView component, ensuring that all course details are accessible on a single screen.


In summary, the "CoreComponents" app successfully adheres to the IPO model by taking input, processing it effectively, and generating a visually appealing and informative output for users.
